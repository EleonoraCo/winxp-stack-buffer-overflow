# winxp-stack-buffer-overflow
Progetto di Sicurezza Informatica incentrato sull'analisi e lo sfruttamento di una vulnerabilità di Stack Buffer Overflow in ambiente Windows XP SP3 (32-bit). Include lo sviluppo di exploit custom in Python, la gestione dei bad characters, l'override di EIP e una fase opzionale di Local Privilege Escalation (Ring 0) tramite exploit KiTrap0D.
